# Sistema de Gestión de Inventarios con TDD y ORM

Este proyecto implementa una base técnica para la actividad de **Pruebas Unitarias y TDD**.

## Componentes
- ORM con SQLAlchemy
- Base de datos SQLite
- Servicios para usuarios y productos
- Pruebas unitarias con unittest

## Ejecución
```bash
pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -p "test_*.py"
```
